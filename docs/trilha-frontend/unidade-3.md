# Unidade III – HTML & CSS Intermediário

**Tempo Estimado**: 4 semanas

Esta unidade é a mais longa da trilha e cobre desde versionamento de código até formulários e responsividade (Módulo 3 e 4 do curso do Gustavo Guanabara). Continue fazendo os exercícios de aula e os desafios do GitHub. **A partir do módulo 3.4**, o professor deixou de atualizar o material de apoio no GitHub, mas é possível acompanhar os desafios e exercícios junto com as aulas.

Os projetos dessa unidade também devem ser entregues via repositórios públicos no GitHub.
