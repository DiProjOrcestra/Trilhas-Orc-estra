# Unidade I - Onboarding

**Tempo Estimado**: 3 dias

Esta unidade prepara o terreno antes de qualquer linha de código: você vai entender como a web funciona por trás dos panos e configurar o ambiente que vai usar em toda a trilha. As unidades de I a IV seguirão o curso de HTML e CSS do professor Gustavo Guanabara no YouTube.

---

### Módulo 1.1: Introdução e Ambientação
Entender como a web funciona (cliente-servidor, DNS, requisições), configurar ambiente (editor de código, terminal) e instalar as ferramentas básicas.
