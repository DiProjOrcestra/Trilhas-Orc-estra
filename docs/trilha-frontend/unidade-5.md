# Unidade V – JavaScript

**Tempo Estimado**: 4 semanas

!!! note "Orientações Importantes: Currículo de JavaScript (freeCodeCamp)"
    A partir daqui, saímos do curso do Guanabara e passamos a seguir o currículo de JavaScript do **[freeCodeCamp](https://www.freecodecamp.org/portuguese/)**. Alguns pontos importantes:

    * Os exercícios do freeCodeCamp estão **em inglês**. Caso você tenha uma boa base na língua, é recomendado segui-los normalmente. Caso não, será disponibilizado material de apoio para ajudar nessa parte.
    * A **ordem dos módulos desta trilha não segue exatamente a ordem do currículo original** do freeCodeCamp. Os últimos dois módulos foram reorganizados para fazer mais sentido dentro da nossa trilha de front-end.
    * O último módulo (Módulo 5.5) está marcado com `*` porque é **opcional nesta primeira passada**. É um conteúdo importante, mas não bloqueia seu avanço para React. Pode voltar a ele depois, com mais calma.

    Os conteúdos marcados como Oficina e Laboratório são essenciais para entender e aplicar os conceitos aprendidos. Além disso, todo conteúdo marcado como **Projeto de Certificação** deve ser tratado como projeto da unidade e entregue via repositório público no GitHub.

---

### Módulo 5.1: Fundamentos e Lógica de Programação
Compreender a sintaxe essencial da linguagem (variáveis, tipos de dados, booleanos, funções, arrays, objetos e loops) e aplicar funções de ordem superior e callbacks para estruturar a lógica inicial dos programas.

📍 **O que fazer no freeCodeCamp:** Estudar do tópico *"Variáveis e Strings"* até *"Funções de Ordem Superior"*.

**Link:**
- 🌐 [Acessar Plataforma freeCodeCamp: Módulo 5.1](https://www.freecodecamp.org/portuguese/learn/javascript-v9/)

---

### Módulo 5.2: Manipulação do DOM, Eventos, Acessibilidade e Depuração
Tornar páginas interativas selecionando elementos e usando event listeners, aplicar boas práticas de acessibilidade em JavaScript, depurar código com as ferramentas do navegador e usar expressões regulares para validar e manipular texto.

📍 **O que fazer no freeCodeCamp:** Estudar do tópico *"Manipulação do DOM e Eventos"* até *"Regex Básico"*.

**Link:**
- 🌐 [Acessar Plataforma freeCodeCamp: Módulo 5.2](https://www.freecodecamp.org/portuguese/learn/javascript-v9/)

---

### Módulo 5.3: Validação de Dados e Orientação a Objetos
Validar formulários, manipular datas e eventos de áudio/vídeo, organizar coleções de dados com Maps e Sets, persistir dados no navegador com localStorage e estruturar código com Classes e princípios de orientação a objetos.

📍 **O que fazer no freeCodeCamp:** Estudar do tópico *"Validação de Formulários"* até *"Classes"*.

**Link:**
- 🌐 [Acessar Plataforma freeCodeCamp: Módulo 5.3](https://www.freecodecamp.org/portuguese/learn/javascript-v9/)

---

### Módulo 5.4: JavaScript Assíncrono e APIs
Lidar com requisições de rede (APIs), gerenciar Promisses e funções assíncronas para buscar e enviar dados externos sem travar a interface da aplicação.

📍 **O que fazer no freeCodeCamp:** Estudar do tópico *"JavaScript Assíncrono"* até *"Revisão de JavaScript"*.

**Link:**
- 🌐 [Acessar Plataforma freeCodeCamp: Módulo 5.4](https://www.freecodecamp.org/portuguese/learn/javascript-v9/)

---

### Módulo 5.5: Algoritmos e Estruturas de Dados (*)
Aplicar recursão e estruturas de dados avançadas (grafos, árvores) para resolver problemas de manipulação de grandes volumes de dados, e usar programação dinâmica e funcional para otimizar soluções.

📍 **O que fazer no freeCodeCamp:** Estudar do tópico *"Recursão"* até *"Programação Funcional"*.

**Link:**
- 🌐 [Acessar Plataforma freeCodeCamp: Módulo 5.5 (Opcional nesta 1ª passada)](https://www.freecodecamp.org/portuguese/learn/javascript-v9/)
