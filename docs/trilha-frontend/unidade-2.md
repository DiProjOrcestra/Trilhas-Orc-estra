# Unidade II – HTML & CSS Básico

**Tempo Estimado**: 3 semanas

A partir daqui, você vai seguir o Módulo 1 e 2 do curso do Gustavo Guanabara. É essencial que você assista às aulas na ordem, faça todos os exercícios propostos durante as vídeoaulas (mesmo os que parecerem simples) e complete os desafios disponíveis no GitHub oficial do professor: [github.com/gustavoguanabara/html-css](https://github.com/gustavoguanabara/html-css).

O projeto final desta unidade (Site Android) deve ser publicado no seu próprio repositório do GitHub. Não se preocupem pois o início da Unidade III irá ensiná-los como fazer isso.
