# Unidade IV – HTML & CSS Avançado

**Tempo Estimado**: 2,5 semanas

Nesta unidade, fechamos a base de HTML e CSS com Flexbox e Grid, os dois sistemas de layout mais usados no mercado hoje. O conteúdo faz parte do Módulo 5 do curso do Guanabara, continue seguindo os exercícios e desafios normalmente.

O projeto de Portfólio também deve ser entregue via repositório público no GitHub. Esse projeto é uma oportunidade para que você consiga exibir tudo que desenvolveu até aqui.

---

### Módulo 4.1: CSS Flexbox
Construir layouts flexíveis de uma dimensão (eixos, alinhamento, crescimento/encolhimento).
