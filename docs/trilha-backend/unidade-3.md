# Unidade III – Java (Estruturas de Dados)

---

## 1. Visão Geral

Nesta unidade intermediária, você aprenderá a trabalhar com as estruturas de dados fundamentais do Java, avançando o nível de manipulação de coleções, funções de ordem superior e novos recursos da linguagem.

---

## 2. Conteúdo e Tópicos Abordados

Aprenda a utilizar:
- Manipulação de Coleções (`ArrayList`, `List`)
- Stream API (filtros, mapeamentos e iterações funcionais)
- Generics (reaproveitamento de tipos genéricos)
- Packages (organização em pacotes)
- Records (classes imutáveis de dados)
