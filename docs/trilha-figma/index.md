# Trilha de Design Figma

---

## 1. Introdução

Este documento padroniza a capacitação interna dos membros da **Orc’estra Gamificação**, servindo como guia oficial para o desenvolvimento de boas práticas de design no Figma. O objetivo principal é capacitar a equipe a construir interfaces profissionais, organizadas, automatizadas e de alta fidelidade.

---

## Módulo 1: Fundamentos & Configuração do Ambiente

### 1.1 Introdução a UX/UI e Tela inicial do Figma
Apresentar o conceito de UX/UI e a diferença entre eles. Visão geral da interface do Figma e como fazer login no Figma Pro com a matrícula da UnB.

**Links:**
- 🎥 [Figma- Tela inicial e perfis](https://youtu.be/tfQYfBVgoZc?si=fHt5DR-TYHlJjsB5)
- 🎥 [Design UX e UI: Tudo Igual ou Tem Diferença?](https://youtu.be/gQzoTVz2w6g?si=JzWCRSKd8tIF58KA)
- 📁 [Capacitação Figma da Orc](https://drive.google.com/drive/folders/1Ujtzk41v_Ea1Fs2CsyB8uppWZldk2joV)

### 1.2 Preparando o Ambiente Figma
Apresentação de funções base para organização. Como configurar e utilizar *Styles* e *Grids* (Colunas para Web e Mobile).

**Links:**
- 🎥 [Grids e Colunas: WEB e Mobile](https://youtu.be/TUZBkOzjjlU?si=zKm1XxUi8yMmv1Yb)

### 1.3 Atalhos Essenciais e Plugins Salva-vidas
Apresentação dos atalhos que dobram a velocidade do fluxo de trabalho no Figma (ex: duplicar, agrupar, focar) e como instalar/usar plugins essenciais (ex: Iconify, Unsplash, Remove BG, etc.).

## Módulo 2: Auto Layout & Layout Responsivo

### 2.1 Auto Layout: O Fim dos "Groups"
Introdução ao *Flexbox* no Figma. A diferença crucial entre usar *Frames* vs *Groups*. Como aplicar o atalho para criar elementos que se adaptam ao conteúdo.

**Links:**
- 🎥 [Auto Layout Figma - Tudo que você precisa saber!](https://youtu.be/nN9Sxuw-aKk?si=0xIR5WiGRhcUrNch)

### 2.2 Auto Layout Avançado
Prática de aninhamento (Frames dentro de Frames). Construção de componentes mais complexos, como *Cards* de serviços responsivos com margens e espaçamentos perfeitos.

**Links:**
- 🎥 [Figma Tutorial: Cards com Auto Layout - Rápido e fácil de fazer!](https://youtu.be/ObrHbReM1cc?si=_bD_wOYaD6I9Su63)

### 4.1 Prototipagem de Alta Fidelidade
Dando vida às telas na aba *Prototype*. Como ligar telas, criar interações como *While Hovering* e utilizar o *Smart Animate* para transições suaves e realistas.

**Links:**
- 🎥 [Figma Protótipo Navegável e Interativo - 10x MAIS RÁPIDO!](https://www.youtube.com/watch?v=MKDpqjxe1Rw)

Como criar telas responsivas no Figma utilizando Auto Layout e Constraints para Web e Mobile, além de explorar o Figma Dev Mode para a facilitação do handoff com a equipe de desenvolvimento Frontend.
