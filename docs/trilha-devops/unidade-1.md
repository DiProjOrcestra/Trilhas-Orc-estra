# Unidade I – Fundamentos de SO & Redes

---

## 1. Visão Geral

Nesta unidade inicial, você aprenderá a base de infraestrutura para qualquer profissional de DevOps: o sistema operacional **Linux** e os fundamentos de **Redes de Computadores** (pilha TCP/IP, modelo OSI e resolução de nomes DNS).
